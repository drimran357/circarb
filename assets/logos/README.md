# CIRCARB website logos

Upload the official logo files in this folder using **Add file → Upload files** on GitHub.

Suggested filenames:

- `circarb-logo.svg` (or `.png`) — CIRCARB main branding
- `university-of-leicester.svg` (or `.png`)
- `aston-university.svg` (or `.png`)
- `loughborough-university.svg` (or `.png`)
- `university-of-edinburgh.svg` (or `.png`)
- `epsrc.svg` (or `.png`) — optional, subject to funding acknowledgement requirements

Please use original approved logos, preferably transparent SVG or high-resolution PNG. Keep any required institutional clear space and do not alter colours or proportions. Once the files are uploaded, the website can be updated to display them in the header, partners section and footer.
